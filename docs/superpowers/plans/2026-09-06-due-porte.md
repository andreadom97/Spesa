# Due porte e primo avvio (P4 e P5) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un utente nuovo trova pasti e ingredienti già pronti al primo accesso, e dallo stato vuoto di Piatti sceglie fra importare la dieta e scrivere i suoi piatti in una schermata veloce; Lista e Settimana vuote lo rimandano lì.

**Architecture:** Dati puri di dominio (i 71 ingredienti e i default per la mini-creazione), una funzione dati idempotente chiamata da un cancello nel layout, una schermata nuova che riusa `salvaPiatto`/`salvaIngrediente`, tre stati vuoti ritoccati. Ogni task chiude con suite verde e un commit.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Supabase, Vitest 4 + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-06-due-porte-design.md`

## Global Constraints

- Nessun cambio a `salvaPiatto`, `salvaIngrediente`, `salvaSlotDefs`, `creaSettimana`, `planner`.
- Copy esatti della spec. Zero affermazioni di salute. Codice, commenti e test in italiano, stile dei file vicini (inline style, mock dei moduli `@/data/*`, controfigura del client come in `src/data/__tests__/lista.generaListe.test.ts`).
- Letture aggiunte alle pagine sempre tolleranti.
- Suite verde a ogni commit: `npx vitest run && npx tsc --noEmit && npm run lint && npm run build`. I subagent non committano.
